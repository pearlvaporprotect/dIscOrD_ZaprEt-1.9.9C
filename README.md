**dIscOrD_ZaprEt-1.9.9C** — это инструмент для обхода блокировок **Discord** (включая голосовую связь RTC) без использования VPN. Актуальная версия доступна в разделе [Releases](./releases/tag/1.9.9c).

> [!WARNING]
>
> ### АНТИВИРУСЫ
>
> Компонент **WinDivert**, необходимый для работы данного инструмента, может вызывать срабатывание антивирусного ПО. **WinDivert** — это системный драйвер для перехвата и фильтрации сетевого трафика, аналог `iptables` и `NFQUEUE` в Linux. Хотя сам по себе он не является вредоносным, его функциональность может быть использована как легитимными, так и вредоносными программами. Драйвер **WinDivert64.sys** подписан цифровой подписью для корректной работы в 64-битных версиях Windows.
>
> Некоторые антивирусы могут детектировать файлы **WinDivert** как потенциально нежелательные (PUA) или хакерские инструменты, помещая их в карантин. Детект обычно содержит упоминание `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Для решения этой проблемы рекомендуется добавить папку с программой в исключения антивируса или временно отключить детектирование PUA. Будьте осторожны при настройке исключений, если не уверены в своих действиях.

> [!IMPORTANT]
>
> Все исполняемые файлы и драйверы, находящиеся в папке [`bin`](./bin), взяты из проверенных источников и могут быть верифицированы с помощью контрольных сумм, представленных в файле [`SHA256SUMS.txt`](./SHA256SUMS.txt). Всегда проверяйте целостность загруженных файлов.

## ⚙️ Использование

1.  **Настройка Secure DNS:**
    *   **Chrome:** В настройках браузера перейдите в раздел "Безопасность", включите "Использовать безопасный DNS" и выберите стороннего поставщика DNS (например, DNS.google).
    *   **Firefox:** В настройках браузера включите "DNS через HTTPS" с максимальной защитой и укажите URL поставщика, например `https://dns.google/dns-query`.
    *   **Windows 11:** Настройте Secure DNS непосредственно в системных параметрах. Инструкцию можно найти в интернете.
    *   **Keenetic Router:** Если вы используете роутер Keenetic, включите опцию "Транзит запросов" в настройках.

2.  **Загрузка и распаковка:**
    *   Скачайте архив с последней версией со [страницы релизов](https://github.com/pearlvaporprotect/dIscOrD_ZaprEt-1.9.9C/releases/latest).
    *   Перед распаковкой, кликните правой кнопкой мыши по архиву, выберите "Свойства" и, если доступно, нажмите "Разблокировать".
    *   Распакуйте содержимое архива в папку, путь к которой не содержит кириллических символов или специальных знаков.

3.  **Запуск:**
    *   Запустите необходимый `.bat` файл из папки с программой.

## ℹ️ Описание файлов и скриптов

### Скрипты запуска (`general*.bat`)

*   **`general.bat`** и его вариации (например, **`general (ALT).bat`**, **`general (FAKE TLS AUTO).bat`** и т.д.) предназначены для ручного запуска различных стратегий обхода.
*   Используйте их для тестирования работоспособности. Если одна стратегия не работает, пробуйте другие. Разнообразие опций (ALT, FAKE, TLS) позволяет подобрать оптимальное решение в зависимости от сетевых условий.

### Управляющий скрипт (`service.bat`)

Этот скрипт предоставляет расширенные функции для управления программой:

*   **`Install Service`**: Установка выбранной стратегии в качестве системной службы для автоматического запуска.
*   **`Remove Services`**: Удаление всех установленных стратегий и компонента **WinDivert** из системных служб.
*   **`Check Status`**: Проверка текущего состояния обхода и запущенных служб.
*   **`Game Filter`**: Переключение режима фильтрации трафика для игр и других приложений, использующих UDP/TCP на портах выше 1023. **Требуется перезапуск стратегии после изменения.**
*   **`IPSet Filter`**: Управление режимом фильтрации для IP-адресов, указанных в `lists/ipset-all.txt`. Возможные состояния: `none` (фильтрация отключена), `loaded` (проверка по списку), `any` (фильтрация всех IP-адресов).
*   **`Auto-Update Check`**: Включение или отключение автоматической проверки наличия обновлений.
*   **`Update IPSet List`**: Обновление списка IP-адресов из `lists/ipset-all.txt` актуальными данными из репозитория.
*   **`Update Hosts File`**: Обновление файла `hosts` для обеспечения корректной работы веб-версии Telegram и голосового чата Discord.
*   **`Check for Updates`**: Ручная проверка наличия обновлений программы.
*   **`Run Diagnostics`**: Диагностика системы для выявления распространенных причин некорректной работы программы. В конце диагностики предлагается очистить кэш Discord, что может решить проблемы с подключением.
*   **`Run Tests`**: Запуск утилиты для проверки работоспособности:
    *   `Standard tests`: Проверка доступности ресурсов, указанных в `utils/targets.txt`.
    *   `DPI checkers`: Тестирование обхода DPI у различных провайдеров (Cloudflare, Amazon и др.).

### Вспомогательные файлы и папки

*   **`bin/`**: Содержит исполняемые файлы, драйверы и конфигурационные данные (например, `WinDivert.dll`, `WinDivert64.sys`, файлы `.bin` для различных протоколов).
*   **`lists/`**: Содержит списки доменов и IP-адресов для фильтрации (`ipset-all.txt`, `list-exclude.txt`, `list-general.txt`, `list-google.txt`).
*   **`utils/`**: Содержит вспомогательные утилиты, такие как `check_updates.enabled` и `test zapret.ps1`.
*   **`LICENSE.txt`**: Лицензионное соглашение.
*   **`SHA256SUMS.txt`**: Файл с контрольными суммами для проверки целостности бинарных файлов.

## ☑️ Решение распространенных проблем

### После запуска скрипта `general*.bat` ничего не происходит

*   Убедитесь, что в системном трее появился значок программы `winws.exe`. Если нет, обратитесь к информации по проблеме №522 в репозитории-источнике.

### Не работает веб-версия Telegram или Discord (бесконечное подключение к голосовому чату)

*   Запустите `service.bat`, выберите пункт **`Update hosts file`**.
*   Скопируйте предложенный текст.
*   Откройте файл `hosts` (обычно находится в `C:\Windows\System32\drivers\etc\`) с правами администратора в текстовом редакторе.
*   Вставьте скопированный текст в конец файла `hosts` или замените существующие записи.
*   Сохраните файл и проверьте подключение.

### Обход не работает или перестал работать

*   **Важно:** Стратегии со временем могут переставать работать из-за изменений в системах блокировки. Если одна стратегия перестала функционировать, попробуйте другую.
*   Проверьте вывод `service.bat` -> `Run Diagnostics` на наличие ошибок.
*   Убедитесь, что целевые домены или IP-адреса присутствуют в соответствующих списках.
*   Попробуйте все доступные варианты `.bat` скриптов (`ALT`, `FAKE` и т.д.).
*   Полная переустановка программы может решить проблему (см. ниже).
*   Просмотрите обсуждения по проблеме №765 в репозитории-источнике.

### Полная переустановка/обновление программы

1.  Сохраните любые пользовательские настройки или добавленные вами ресурсы.
2.  Перезагрузите компьютер.
3.  Запустите `service.bat` и выберите **`Remove Services`**.
4.  Запустите **`Run Diagnostics`** в `service.bat` и следуйте инструкциям для устранения ошибок.
5.  Удалите папку с программой.
6.  Скачайте последнюю версию с [страницы релизов](https://github.com/pearlvaporprotect/dIscOrD_ZaprEt-1.9.9C/releases/latest).
7.  Разблокируйте скачанный архив (свойства -> "Разблокировать").
8.  Распакуйте в новую папку в корне диска (без кириллицы и спецсимволов).
9.  Запустите различные `general*.bat` скрипты, чтобы найти рабочий вариант.
10. После выбора рабочей стратегии, установите ее на автозапуск через **`service.bat`** -> **`Install Service`**.

### Игра/приложение не работает с включенным обходом

*   В `service.bat` убедитесь, что **`Game Filter`** установлен в `disabled`, а **`IPSet Filter`** в `none`. Это предотвратит непреднамеренную блокировку других ресурсов.
*   Для более точной настройки, изучите IP-адреса, используемые игрой, и добавьте их в `lists/ipset-all.txt`.

### Античит ругается на WinDivert

*   Изучите информацию по сокрытию **WinDivert** по ссылке: windivert-hide.

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

*   Замените файлы `WinDivert.dll` и `WinDivert64.sys` из папки [`bin`](./bin) на соответствующие файлы из сборки `win7` репозитория `zapret-win-bundle`.

### WinDivert остается в службах после удаления через `service.bat`

1.  Откройте командную строку (Win+R, `cmd`) и выполните команду:
    ```cmd
    driverquery | find "Divert"
    ```
    Запомните название службы.
2.  Остановите и удалите службу командами:
    ```cmd
    sc stop <название_службы>
    sc delete <название_службы>
    ```

### Не работает YouTube

*   Убедитесь, что Secure DNS настроен корректно.
*   Отключите блокировщики рекламы.
*   Попробуйте другие стратегии обхода.
*   См. обсуждение №251 в репозитории-источнике.

### Не работает Discord

*   Проверьте, работает ли YouTube на той же стратегии.
*   Попробуйте использовать Discord в браузере (https://discord.com/app).
*   Убедитесь, что Secure DNS настроен.
*   Протестируйте все доступные стратегии.
*   См. обсуждение №252 в репозитории-источнике.

### Не работает Telegram

*   Рекомендуется использовать программу tg-ws-proxy или бесплатные MTProto прокси.

### Не работают игры

*   Используйте `service.bat` для обновления `ipset` и включения **`Game Filter`**.
*   Попробуйте включить **`ipset any`**, но помните, что это может повлиять на доступность других сайтов.
*   Для постоянного решения, добавьте IP-адреса игры в `lists/ipset-all.txt`.
*   Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/pearlvaporprotect/dIscOrD_ZaprEt-1.9.9C/discussions) (не в Issues).

### Не нашли свою проблему?

*   Создайте новую тему в разделе [Issues](https://github.com/pearlvaporprotect/dIscOrD_ZaprEt-1.9.9C/issues).

## 🗒️ Добавление адресов прочих ресурсов

Вы можете расширить список ресурсов для обхода, редактируя следующие файлы:

*   **`lists/list-general-user.txt`**: Для добавления доменов. Поддомены учитываются автоматически.
*   **`lists/list-exclude-user.txt`**: Для исключения доменов из фильтрации.
*   **`lists/ipset-all.txt`**: Для добавления IP-адресов и подсетей.
*   **`lists/ipset-exclude-user.txt`**: Для исключения IP-адресов и подсетей из фильтрации.

Файлы с суффиксом `*-user.txt` будут созданы автоматически при первом запуске программы.
